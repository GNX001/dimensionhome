================================================================
维度之家 / Dimension Home   v1.0.0
================================================================

【必需前置 MOD】
    Custom Portal API Reforged 1.0.2
    MOD ID：cpapireforged
    jar 文件名：customportalapi-reforged-1.0.2.jar

    ★ 这是必需前置，不是可选项。缺少它，游戏会在启动时直接崩溃，
      并在日志里报：
        Missing or unsupported mandatory dependencies:
        Mod ID: 'cpapireforged', Requested by: 'dimensionhome'
    请把这个 jar 和本 MOD 的 jar 一起放进 mods 文件夹。

----------------------------------------------------------------
【运行环境】
    Minecraft   1.20.1
    Forge       47.4.10 或更高（已实测 47.4.10 / 47.4.26）
    Java        17
    侧别        客户端与服务端都需要（side = BOTH）

----------------------------------------------------------------
【安装】
    1. 把 customportalapi-reforged-1.0.2.jar 放进 mods 文件夹
    2. 把 dimensionhome-1.0.0.jar          放进 mods 文件夹
    3. 完全重启游戏
    4. 在「Mods」列表里应当同时看到两个 MOD：
         - Custom Portal API ReForged
         - Dimension Home

    多人服务器同理：两个 jar 都要放进服务器的 mods 文件夹。

----------------------------------------------------------------
【怎么玩】
    1. 用平滑石（minecraft:smooth_stone）搭一个门框，
       内腔至少 2 格宽 × 3 格高（最大 21 × 21）
    2. 用打火石点燃门框内部，生成传送门
       （传送门是金色的；进出时的屏幕蒙版也是金色）
    3. 站进门里约 4 秒，即可抵达「维度之家：空岛」
    4. 空岛上有一扇门，走进去就能原路返回

    主世界、下界、末地都可以用平滑石搭门进入空岛。
    返回时会回到你出发的那个维度、原来那扇门旁边。

----------------------------------------------------------------
【空岛规则】
    - 空岛是纯虚空，除了落脚平台什么都没有
    - 落脚平台与门等宽（含两侧门框），并沿门的前后方向各延伸 2 格
    - 空岛上也用平滑石 + 打火石，但要搭在落脚平台周围的
      「可点燃区域」内（水平 ±12 格，竖直 99 ~ 122 格）
    - 可点燃区域内可以随时点燃任意形状的门，但同一时间
      只允许存在一扇门
    - 区域内已有一扇门时，点燃第二扇会被拒绝
    - 空岛上的第一扇门，会按你第一次进入时那扇来源门的
      形状与朝向自动复刻

    ★ 所以门被拆掉也不会被困：在区域内重新搭一扇门点燃即可。

    注意：玩家、怪物、动物、掉落物**都能**穿过传送门进出空岛。
    也就是说怪物会跟着你进门，请自行清理。

    （从更早的版本升级上来时，旧版那块写死的 3×3 平台留在门后的
      几格会在开服时自动清掉，不会留下悬空的半截石台。）

----------------------------------------------------------------
【兜底逃生】
    如果连搭门的材料都没了（例如打火石和平滑石都掉进虚空），
    可以在空岛内执行：

        /dimensionhome home

    会立刻把你送回原来的维度、原来那扇门旁边。

----------------------------------------------------------------
【自检命令】（OP / 单人作弊开启后可用）
    /dimensionhome selftest   检查维度参数、虚空、地标与点燃规则
    /dimensionhome tptest     检查传送全链路与来源记录
    /dimensionhome home       兜底逃生（同上）

----------------------------------------------------------------
【常见问题】
    Q: 启动时崩溃，日志写 "Missing or unsupported mandatory
       dependencies: Mod ID: 'cpapireforged'"？
    A: 少放了前置。把 customportalapi-reforged-1.0.2.jar 放进
       mods 文件夹，然后完全重启游戏。

    Q: 打火石点不着？
    A: 确认门框用的是「平滑石」（smooth_stone），不是石砖、
       台阶或其它变体；内腔要留空，至少 2 宽 × 3 高。
       在空岛上，还要确保位置在可点燃区域（水平 ±12 格、
       竖直 99 ~ 122 格）之内，并且区域内还没有别的门。

    Q: 进不去空岛？
    A: 站进门里大约需要 4 秒（创造模式约 1 秒）。

    Q: 返回时落在了别处？
    A: 返回点优先取你走进门之前最后一次站的安全位置；
       该位置已失效时会退回你原来那扇门的坐标。
