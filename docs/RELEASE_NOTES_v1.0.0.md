# 维度之家 · Dimension Home v1.0.0

第一个正式版本。Forge 1.20.1 的纯虚空私人空岛维度 MOD。

> 用**平滑石**搭一扇门、打火石点燃，就能进入纯虚空的空岛；
> 再走回来时，你会回到**出发的那个维度、原来那扇门**旁边。

---

## 核心特性

| 特性 | 说明 |
| --- | --- |
| 坐标缩放 | **1:1** —— 主世界走 100 格，空岛也是 100 格（**不是**下界式 8:1） |
| 门颜色 | **金色 `#FFD700`**（门方块、传送时的屏幕蒙版、门口粒子三处统一） |
| 昼夜 | 有昼夜交替 |
| 天空光照 | 有（`has_skylight = true`） |
| 地形 | **纯虚空** —— 不生成浮空岛、矿物、树木、结构、村庄 |
| 落脚平台 | 与门（含左右门框）**等宽**，沿门法线前后各延伸 **2 格** |
| 返回逻辑 | 回到**出发的维度**、**原来那扇门**旁边（下界进就从下界出，末地进就从末地出） |
| 门框架方块 | `minecraft:smooth_stone`，打火石点燃，任何维度都能搭 |
| 生物生成 | 同主世界（会刷怪，但不触发袭击） |
| 实体通行 | **玩家、怪物、动物、掉落物都能穿过门**，各自原路返回 |
| 床 | 可以用 |
| 重生锚 | 不能使用 |

## 空岛规则（重点）

空岛是一片纯虚空。为了既保持「只有一扇门」的设计，又**不会因为门被拆掉而被困**，
空岛上的点燃规则与主世界不同：

- 空岛内划定一块**可点燃区域**（水平 ±12 格，竖直 y=99 ~ 122）
- **区域内**可以随时点燃**任意形状**的门框（宽 2~21、高 3~21），但**同一时间只允许一扇门**
- 区域内**已有门**时，点燃第二扇会被**拒绝**
- **区域之外**点燃会被**拒绝**
- 空岛的**第一扇门**会按「第一次有人进门时那扇来源门」的**形状与朝向自动复刻**
- 所以：**门被拆掉也不会被困** —— 在区域内重新搭门框、点燃即可

> 兜底：如果连打火石和平滑石都掉进虚空了，空岛内执行 `/dimensionhome home` 直接逃生。

**[Custom Portal API Reforged 1.0.2](https://www.curseforge.com/minecraft/mc-mods/custom-portal-api-reforged)**
（MOD ID：`cpapireforged`）

**这是必需前置，不是可选项。** 缺少它游戏会在启动时直接崩溃，日志报：

```
Missing or unsupported mandatory dependencies:
Mod ID: 'cpapireforged', Requested by: 'dimensionhome'
```

装的时候 `mods\` 里必须**同时**有：

```
mods\
├─ dimensionhome-1.0.0.jar              ← 本 MOD
└─ customportalapi-reforged-1.0.2.jar   ← 必需前置（107,408 字节）
```

## 怎么玩

1. 挖石头烧成**平滑石**，搭一个门框，内腔至少 **2 格宽 × 3 格高**
2. 拿**打火石**对着门洞内侧底部右键 → 门洞被一层**金色**填满
3. 站进去约 **4 秒**（创造模式约 1 秒）→ 抵达空岛
4. 空岛上有唯一一扇返回门，走进去就回到你出发的地方

## 内置自检命令

```
/dimensionhome selftest    # 维度参数 / 纯虚空 / 地标几何 / 点燃规则 / 注册状态（40 项）
/dimensionhome tptest      # 传送全链路：玩家 + 掉落物各跑一遍完整往返（26 项）
/dimensionhome home        # 兜底逃生（只在空岛维度内有效）
```

需要 OP 或单人作弊权限。

## 从更早的版本升级

早期版本的空岛平台是写死的 3×3。升级到本版本后，旧平台残留在门后、
不属于新平台范围的平滑石会在开服时**自动清理**（只删当前确实是平滑石的格子，
玩家自己放的方块不会被动）。
